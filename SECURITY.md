# Security

Report a vulnerability privately: on this repository's **Security** tab, choose
**Report a vulnerability**. Please do not open a public issue for it.

A useful report names the release or commit, what an attacker gains (coins, a
key, a signature the person did not mean to give, a sign-in to another site),
and the steps or a test that show it.

In scope is everything in this repository: the app, the off-chain signing
of [SIGNING.md](SIGNING.md), and the release workflow and its signing of the
Android app. Flaws in the chain, the node or the programs belong to the
[Ting repository](https://github.com/ting-organization/ting/security).

Fixes ship in new releases. The app does not update itself, so a release
note says when an update matters for safety.
